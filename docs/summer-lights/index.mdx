# 简介 · <FntColor color="#269ffe">OFFC Summer Lights</FntColor>

<img src="/img/cover-s2.jpg" alt="芙兰朵露与古明地恋的卡通图像，简介头图"/>

绿荫下的石头凳上，<FntColor color="#d05677">芙兰朵露·斯卡雷特</FntColor>端正地坐着。她身前的石头桌上摆着一副不知道弄哪里弄来的棋，棋盘旁边的小碗里盛有一堆五颜六色的棋子。

一阵热热的风吹过。同样不知从哪里来的，戴黑色帽子的<FntColor color="#8bc34a">绿色的古明地恋</FntColor>悄悄出现在视野。

<Highlight color="#d05677">“我就知道你会来。那，开始吧。”</Highlight>芙兰朵露用邪恶的眼神盯着她，冰冷的语气杀死了午后的热浪。

不明觉厉的恋坐在了对面。她琢磨着那空空的棋盘，眼睛瞪得大大的。

突然，芙兰朵露从碗里拎出一枚棋子，重重摔在了棋盘上面。

<Highlight color="#d05677">“接下来，轮到你了！”</Highlight>她充满杀气的口吻中，隐约能感受到一丝恐惧的颤抖。

恋不语，只是一味地冲她傻笑。

......

两个在盛夏相遇的女孩子，在一起经历了一系列流连忘返的旅途后，不知为何走到了你死我活的地步。

芙兰朵露坚信，这只是一场梦。现在，她要亲手了结这个折磨了她495年的噩梦。
