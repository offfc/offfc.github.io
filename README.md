# offfc.github.io

![Social Card](card.jpg)

The official website for **osu! FumoFumo Cup** (*OFFC*), built with [Docusaurus](https://docusaurus.io) and [React](https://react.dev/).

**osu! FumoFumo Cup** (*OFFC*) 的官方网站，使用 [Docusaurus](https://docusaurus.io) 与 [React](https://react.dev/) 技术构建。

## Building

Install dependencies:

```bash
npm install
```

Then simply launch the development server locally with:

```bash
npm run start
```

A website instance should be available shortly.

## Contributing

We welcome contributions to the **osu! FumoFumo Cup** website! Here's how you can help:

### Ways to Contribute

- **Documentation**: Improve or translate existing documentation in the `docs/` directory
- **Blog Posts**: Write articles about tournament updates, results, or community highlights in the `blog/` directory
- **Code Improvements**: Enhance the website's functionality, fix bugs, or improve performance
- **Design**: Contribute to the visual design and user experience
- **Content**: Add new pages, update tournament information, or create new sections

### Development Workflow

1. **Fork the repository** and clone it to your local machine
2. **Create a new branch** for your changes:
   ```bash
   git checkout -b feature/your-feature-name
   ```
3. **Install dependencies** and start the development server:
   ```bash
   npm install
   npm run start
   ```
4. **Make your changes** and test them locally
5. **Build the website** to ensure there are no errors:
   ```bash
   npm run build
   ```
6. **Commit your changes** with clear, descriptive commit messages
7. **Push to your fork** and submit a pull request to the `main` branch

### Pull Request Guidelines

- Provide a clear description of your changes
- Reference any related issues
- Ensure your code follows the existing style and conventions
- Test your changes thoroughly before submitting
- Be responsive to feedback and review comments

### Code of Conduct

Please be respectful and considerate in all interactions. We aim to maintain a welcoming and inclusive community for everyone.
