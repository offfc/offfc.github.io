# offfc.github.io

![Social Card](card.jpg)

The official website for **osu! FumoFumo Cup** (*OFFC*), built with [Docusaurus](https://docusaurus.io) and [React](https://react.dev/).

**osu! FumoFumo Cup** (*OFFC*) 的官方网站，使用 [Docusaurus](https://docusaurus.io) 与 [React](https://react.dev/) 技术构建。

## Building

Install dependencies:

```bash
npm install
```

Then simply launch the development server locally with:

```bash
npm run start
```

A website instance should be available shortly.
